每天只有 **1 小时**，原计划不能简单按比例缩短。一个月总共约 30 小时，更现实的目标是：

> 完成一个“纯文本科研文档 RAG 后端”，掌握核心原理，并能在面试中讲清楚。

暂时不要同时做多模态、Qdrant、BM25、Reranker、LangGraph、MCP 等全套内容。先形成一条完整链路：

```text
Python
→ FastAPI
→ LLM API
→ PDF 解析
→ Chunk
→ Embedding
→ FAISS
→ RAG
→ Evaluation
→ README
```

## 每天 1 小时怎么分配

建议固定成下面的节奏：

```text
5 分钟：复习昨天内容
15 分钟：学习一个新概念
35 分钟：写代码
5 分钟：记录问题并 Git commit
```

不要一小时全部看视频。至少保证一半时间在写代码。

## Day 17：Chunk

实现最简单的字符切块：

```python

    ...
```

```text

chunk 太小：上下文容易被切断
overlap：保留相邻块的部分上下文
```

# 算法题怎么安排

每天只有一小时，不建议再额外要求自己每天刷 1～2 道题。

改成每周做 2～3 道经典题。当天从项目时间里拿出最后 15～20 分钟即可。

优先做：

```text
两数之和
有效括号
反转链表
二分查找
二叉树层序遍历
滑动窗口
TopK
```

一个月完成 8～10 道，并真正能讲清解法，比快速刷 40 道更有效。

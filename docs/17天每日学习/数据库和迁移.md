# 三、你项目中的 ORM 是什么？

你现在不是直接写 SQL：

比如：

```sql
INSERT INTO knowledge_bases
(name)
VALUES
('公司制度');
```

而是：

Python:

```python
kb = KnowledgeBase(
    name="公司制度"
)

session.add(kb)

session.commit()
```

SQLAlchemy 会帮你转换：

变成：

```sql
INSERT INTO knowledge_bases...
```

这叫：

> ORM（Object Relational Mapping）

关系：

```
Python对象

KnowledgeBase()

      |
      |
      ↓

数据库表

knowledge_bases
```

---

# 四、Session 是什么？

这是你之前问过的重点。

很多新人误解：

Session = 数据库连接

其实：

不是。

更准确：

> Session 是一次数据库操作上下文。

例如：

```python
session.add(kb)

session.commit()
```

流程：

```
Python对象

     |
     |
 Session

     |
     |
 SQL

     |
     |
 PostgreSQL
```

---

你的项目：

```python
SessionLocal=sessionmaker(...)
```

创建：

```
请求来了

↓

创建Session

↓

执行查询

↓

commit

↓

关闭Session
```

# 九、Migration 文件里面有什么？

比如：

你的：

```
e780fe_create_core_rag_tables.py
```

里面：

```python
def upgrade():

    op.create_table(
        "knowledge_bases",
        ...
    )



def downgrade():

    op.drop_table(
        "knowledge_bases"
    )
```

---

两个方向：

升级：

```
没有表

↓

创建表
```

降级：

```
有表

↓

删除表
```

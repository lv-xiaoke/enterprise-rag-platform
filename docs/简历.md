## 学术科研

### 2025.09 - 至今 | FLRR：多分辨率图像聚类算法研究与实现 | 第一负责人

- **项目背景**：针对传统聚类需统一尺寸导致**信息丢失**及**高算力成本**问题，设计适用于真实数据的**无监督聚类方法**，显著提升在多分辨率、噪声及遮挡场景下的模型鲁棒性
- **核心工作**：提出 FLRR 方法，将图像建模为连续函数并投影至低维空间；构建结合稀疏降噪与谱聚类的低秩自表示模型；推导连续到离散的优化等价关系并用 **AO-ADMM 算法**求解
- **项目成果**：在 5 个主流数据集上 ACC / NMI / PUR 均达到 **SOTA 性能**；实现混合分辨率免 resize 稳定聚类，且在处理较高分辨率图像时较传统张量方法显著降低计算量；目前该项目即将进入**投稿阶段**

OCR 是 **Optical Character Recognition**，中文一般叫 **光学字符识别**。

它的作用可以简单理解成：

> **把图片里的文字“看出来”，再转换成真正可以复制、搜索、处理的文本。**

比如有两种 PDF：

```text
PDF A
里面的文字本身就是文本
→ 鼠标可以直接选中复制
→ 不需要 OCR
```

```text
PDF B
其实是扫描件，每一页都是一张图片
→ 鼠标选不中文字
→ 需要 OCR 识别图片中的文字
```

举个例子，一张图片里写着：

```text
RAG 可以减少大模型幻觉
```

电脑原本只知道这是一堆像素。OCR 处理之后，会输出类似：

```python
"RAG 可以减少大模型幻觉"
```

然后你的程序才能进一步做：

```text
PDF
↓
OCR
↓
文本
↓
Chunk 切分
↓
Embedding
↓
向量数据库
↓
RAG 检索
```

而我刚才给你生成的 `sample.pdf` **不需要 OCR**，因为它里面存的本来就是真实文本，直接用 PDF 文本解析工具提取就行。

所以你现在学习 PDF 处理时，可以先记住这个判断方法：

> **鼠标能选中文字 → 优先直接提取文本。**  
> **鼠标选不中，只能像看图片一样看 → 很可能需要 OCR。**

常见 OCR 工具有 **Tesseract OCR、PaddleOCR、EasyOCR** 等。等你后面做 RAG 的 PDF 解析时，通常会先处理普通文本 PDF，再进一步处理扫描版 PDF + OCR。

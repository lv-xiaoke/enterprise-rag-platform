问题：**员工请假应提前多久申请，需要谁审批？**

回答：

> 根据参考资料：
>
> - **年假提前申请时间**：一天以内的年假应至少提前 **3 个工作日**在系统提交；连续三天以上年假须至少提前 **7 个工作日**申请。
> - **紧急情况**：无法提前申请时，员工应在当日上班后 **2 小时内**通知直属负责人，并在恢复工作后的 **1 个工作日内**补交申请。

## Docker 重试

同日再次执行隔离 Compose 项目的 `build api web`，仍在 python/node/nginx 基础镜像元数据阶段失败：`auth.docker.io/token` 的 IPv6 连接超时。应用构建步骤尚未开始；没有修改系统 DNS、代理或 Docker 全局设置，也没有触碰开发数据库。完整新镜像及 Compose/Nginx 验收仍待网络恢复。

**后续更新：上述 Docker 阻塞已解决。** 用户追问处理方式后，逐层验证发现本地代理 `127.0.0.1:7877` 可达，而 BuildKit 客户端直连超时。给构建终端设置代理环境变量，并为容器 RUN 阶段指定 `host.docker.internal:7877` 后，全新 API/Web 镜像构建和隔离 Compose 启动均通过，迁移成功、三个常驻服务 healthy。通过真实 Edge 和 Nginx/API 核验注册、建库、PDF入库、SSE、历史与权限。容器验收没有额外调用外部 LLM，也没有修改任何全局网络设置。最终状态与运行条件见 [第一轮验收记录](AI全栈第一轮升级计划.md#docker-网络修复及最终运行条件)。

## 容器网页真实模型补验
